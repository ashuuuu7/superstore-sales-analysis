🚀 End-to-End Data Analysis Project using **Python, SQL & Excel**

---

## 🧠 Project Overview
This project focuses on analyzing retail sales data using a complete data pipeline:
**Python (Data Cleaning) → SQL (Analysis) → Excel (Dashboard)**

The goal is to convert raw data into meaningful business insights and visualize them using an interactive dashboard.

---

## 🛠️ Tools & Technologies
- Python (Pandas)
- SQL (MySQL)
- Microsoft Excel (Pivot Tables, Charts, Slicers)

---

## 🔄 Project Workflow

### 1️⃣ Data Cleaning (Python - Pandas)
- Removed missing values and duplicates
- Converted date columns into proper format
- Cleaned inconsistent data
- Exported cleaned dataset

---

### 2️⃣ Data Analysis (SQL)
- Total Sales & Profit calculation
- Category-wise performance analysis
- Monthly sales trends
- Top 5 products by sales
- Used SQL functions: `SUM`, `COUNT`, `GROUP BY`

---

### 3️⃣ Data Visualization (Excel Dashboard)
- KPI Cards (Total Sales, Profit, Orders, Avg Order Value)
- Sales Distribution (Pie Chart)
- Top 5 Products (Bar Chart)
- Monthly Performance (Line Chart)
- Interactive Filters (Slicers):
  - Category
  - Region
  - Segment
  - Ship Mode
